# Descripción
This [.tar file](https://challenge-files.picoctf.net/c_fickle_tempest/4e504d8229a455fa2c35c2c29c109d92388299b76a4fb323438c2b621a82e329/1000.tar) got tarred a lot.
# Solución
picoCTF{l0t5_0f_TAR5}
En este reto analicé un archivo comprimido que había sido empaquetado múltiples veces en formato TAR. Para evitar descomprimirlo manualmente, utilicé un script que extraía automáticamente cada capa hasta llegar al archivo final. Al abrir el último archivo obtenido encontré la bandera.

```
mkdir like1000
cp 1000.tar like1000/
cd like1000

f="1000.tar"
while true; do
    tar -xf "$f"
    rm "$f"
    f=$(find . -maxdepth 1 -type f | sed 's|^\./||' | head -n 1)
    [ -z "$f" ] && break
    file "$f"
done

cat *.txt
```
